# 📝 Text Summarizer Web App

This is a simple **Text Summarizer** web application built with **Python** and **Streamlit**.  
It uses a transformer-based model from Hugging Face to generate concise summaries of long texts.


## 🚀 Features

- Easy-to-use web interface
- Enter or paste large text blocks
- Get short, meaningful summaries
- Adjustable summary length
- Powered by Hugging Face Transformers


## 🛠️ Technologies Used

- Python
- Streamlit
- Hugging Face Transformers
- PyTorch


## 📦 Installation

1. **Clone the repository**

git clone https://github.com/ambily08/text-summarizer-app.git
cd text-summarizer-app

2. **Install the required packages**

pip install -r requirements.txt

3. **Run the app**

streamlit run app.py
